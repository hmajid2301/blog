By day I’m a backend software engineer [at …]. By night, and most weekends, I’m usually rebuilding something that already worked: my NixOS config, my homelab, or my Neovim setup.

This blog started in September 2018 with a post about running React Native in VirtualBox. Since then it has drifted from Python and React Native towards Go and Nix. It now holds 225 posts, 75 of them short TILs: small fixes I wanted to be able to find again.
